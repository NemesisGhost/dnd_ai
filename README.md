# D&D AI World Platform

D&D AI is a self-hosted campaign application for tabletop role-playing games. A Game Master can build a shared world, run sessions on a timeline and reveal different information to different players. PostgreSQL holds canon, history and audience-specific knowledge. The React portal uses a FastAPI backend. FoundryVTT and model providers are optional.
